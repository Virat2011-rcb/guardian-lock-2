# Guardian Watch setup

Guardian Watch is the Wear OS companion for Guardian Lock. It does not know the Guardian PIN and it does not contain the laptop private key. It creates its own Android Keystore signing key and the phone verifies watch commands using the paired watch public key.

## What was added

- New Android module: `wear`
- Watch app package: `com.morningsearch.guardianwatch`
- Nearby transport: Wear OS Data Layer
- Remote transport: Guardian cloud command relay
- Supported commands:
  - `locate_now`
  - `lock`
  - `alarm_on`
  - `alarm_off`
  - `flashlight_on`
  - `flashlight_off`
  - `lost_mode_on`
  - `found_device`
  - `status`
  - `cctv_on` / `cctv_off` (visible CCTV Monitor Mode)
- Phone app now supports a guardian-authorized watch public key.

## Build

From the project root:

```powershell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :wear:assembleDebug
```

Generated debug APKs:

```text
app/build/outputs/apk/debug/app-debug.apk
wear/build/outputs/apk/debug/wear-debug.apk
```

For updating a Device Owner phone already running the release APK, sign the updated phone APK with the same old release keystore. Do not install a debug APK over the release app.

## Phone setup

1. Install/update the Guardian Lock phone app.
2. Open Guardian Lock on the phone.
3. Make sure Device Owner, Accessibility, and Guardian PIN are active.
4. Tap `Pair Guardian Watch`.
5. Enter Guardian PIN.
6. Enter the 7-digit pairing code generated by the watch. Codes expire after 15 minutes.

## Watch setup

1. Install Guardian Watch on Samsung Galaxy Watch 4 Classic.
2. Open Guardian Watch.
3. Tap `Settings / Pairing`.
4. Set:

```text
Cloud URL = https://your-guardian-dashboard-domain
Recovery token = same GUARDIAN_TOKEN as the dashboard server
```

5. Tap `Save & Generate 7-digit Code`, then keep the code visible.
6. On the phone, enter that code in `Pair Guardian Watch` after guardian PIN authentication.

## CCTV Monitor Mode

This is an explicit, visible camera-monitoring mode. It requires camera permission and keeps a visible monitor screen with a Stop button; it is not a hidden camera or background spy mode. Start it from the phone's `Guardian Recover: CCTV Monitor Mode` button, the laptop dashboard `CCTV Monitor On`, or the watch `CCTV Monitor` button. Motion events are uploaded to the configured recovery server and the watch polls for new events while its app is open and network access is available.

## Transport behavior

Guardian Watch tries:

1. Nearby Phone via Wear OS Data Layer.
2. Cloud relay if nearby phone is unavailable.

The cloud server only queues signed commands. The phone still verifies the watch signature before applying commands.

## Testing checklist

- Watch home shows last phone status.
- `Locate Phone` works when phone is nearby.
- `Locate Phone` queues through cloud when phone is not nearby.
- Lost Mode requires confirmation.
- Found Device requires confirmation.
- Replay/expired/invalid signatures are rejected by phone verifier.
- Phone app still accepts existing laptop dashboard signed commands.
